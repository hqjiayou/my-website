# `doc/` 目录说明（兼容占位）

本目录 **不再维护权威正文**。仓库文档权威路径统一为仓库根目录下的 **`docs/`**：

| 类型 | 权威路径 |
| --- | --- |
| Java 后端（website-services）设计、数据库模型、环境说明 | [`docs/website-services/`](../docs/website-services/) |
| 数据库数据字典 | [`docs/数据字典/`](../docs/数据字典/) |
| 仓库整体架构说明 | [`docs/整体架构说明.md`](../docs/整体架构说明.md) |
| Admin Web 专项文档 | [`docs/admin-web/`](../docs/admin-web/) |

为兼容历史链接或书签，`doc/` 下同名 Markdown **仅保留一页跳转说明**，请勿在此处追加长篇正文。
