> 功能注解：约束 admin-web 页面模块的拆分方式、引入方式与文件注释规范。

# 页面开发规范

## 1. 页面组织
- 页面文件放在 `src/pages/<domain>/`，按业务域拆分。
- 页面级组件建议以 `*-page.tsx` 命名。
- 页面内部可继续拆分为 `components/`, `hooks/`, `locales/` 等子目录。

## 2. API 引入
- 页面层统一通过 `@/api` 引入接口，不直连 mock 文件。
- 页面层不直接发起 axios 请求，所有请求都走 `api` 模块。

## 3. 状态与数据流
- 远程数据优先使用 `react-query` 管理。
- 页面只处理展示与交互，不承载跨页面的复杂业务状态。

## 4. 注释要求
- 除 `tsx` 文件外，新增/修改文件必须在首部加“功能注解”。
- 推荐统一格式，便于后续自动检查。
