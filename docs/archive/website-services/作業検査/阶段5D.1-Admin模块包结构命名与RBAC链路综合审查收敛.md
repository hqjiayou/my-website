# 阶段 5D.1 — Admin 模块包结构、命名职责与 RBAC 链路综合审查收敛

## 1. 阶段背景

RBAC 主线 5A～5D 功能已成立。本阶段**不新增业务能力**，对 Admin 模块做结构审查与小范围收敛，避免 `controller` 与 `rbac/controller` 混用、Controller 承担 Service 职责、DTO 混入内部快照、Security 包混入业务保护规则等问题继续扩散。

## 2. 审查范围

| 模块 | 范围 |
|------|------|
| **admin** | `config` / `constant` / `controller` / `dto` / `entity` / `handler` / `mapper` / `security` / `service` |
| **关联** | gateway、auth、common、infra、agent（边界核对，本轮不改其业务） |

## 3. 审查角度

1. **模块与文件关联**：跨模块依赖、Controller→Mapper、test-only 进 main  
2. **命名与职责**：按层分包 + 类名表达功能；拒绝 manager/facade/converter 膨胀  
3. **RBAC 全链路**：登录 → 验签 → 快照 → Method Security → 管理接口 → `/auth/me`

## 6. 分项收敛说明

### 6.1 Config

- 删除 `AdminMethodSecurityConfig`；`@EnableMethodSecurity` 在 `AdminSecurityConfig`  
- 清理未使用 import；`SecurityFilterChain` / `AdminJwtDecoderConfig` / `AdminOpenApiConfig` 未改逻辑  

### 6.2 Controller

- **`AdminAuthMeController`**：仅注入 `AdminAuthMeService`，不再直接访问 `AdminUserMapper`  
- **`AdminPingController`**：移除 `AgentClient`；`/api/admin/ping` 仅返回 Admin 自身 ready  

### 6.3 DTO 与内部模型

- **`AdminRbacDtos`**：仅 RBAC HTTP 契约  
- **`AdminCurrentAuthorizationSnapshot`**：请求级 RBAC 快照，供 Holder / Checker / QueryService  

### 6.4 Constant

- main 保留 `ROLE_SUPER_ADMIN`、`STATUS_ACTIVE`  
- `admin:rbac:check` 仅在 test（不进 main、不进生产 Flyway）  

### 6.5 Security

- 保留 EntryPoint、Filter、Checker、Holder、Snapshot  
- **不**再放 super_admin 业务保护（已迁至 `AdminRoleGuard`）  

### 6.6 Handler

- `GlobalExceptionHttpStatus` 注释修正为 `handler` 包（非 `handler/support`）  
- `GlobalExceptionHandler.handleException` 增加 `log.error`（响应结构不变）  

### 6.7 Mapper（本轮记录、未拆 SQL）

| 项 | 结论 |
|----|------|
| `AdminRbacQueryMapper` | 职责偏泛，暂不拆；后续可拆 Authorization / RolePermission 查询 |
| `AdminRoleManagementMapper` | `countActiveUsersByRoleId` 职责清楚，保留 |
| `AdminUserRoleManagementMapper` | 绑定查询不强制 ACTIVE（管理展示）；**权限生效**由 `AdminRbacQueryMapper` 过滤 ACTIVE |
| SQL 拼接 `STATUS_ACTIVE` | 待统一 `CommonStatus` / `RecordStatus` 时再收敛 |

### 6.8 Service

- `AdminPermissionManagementServiceImpl`：import 与空行整理  
- `findActiveByRoleCode` → **`findByRoleCode`**：仅配合 `@TableLogic` 查未删除行，**不按 ACTIVE 过滤**（用于 role_code 唯一性校验）  
- **`deleteById`**：`AbstractAuditableEntity` 含 `@TableLogic` → **逻辑删除**，替换绑定符合软删设计  
- `AdminUserRoleManagementServiceImpl` 内 `AuthContext` 解析：本轮保留，不抽 `CurrentAdminUserProvider`  

## 7. 模块依赖边界

| 边界 | 结论 |
|------|------|
| Auth ↔ RBAC | Auth **不**做 RBAC；JWT **无** permissions |
| Gateway ↔ RBAC | Gateway **不**判权 |
| Admin → Agent | **Ping 已解耦**；`agent` 仍在 classpath（`DefaultAgentClient` Bean），后续可考虑缩小 pom 范围 |
| Admin → Auth | **无** Maven 依赖 auth 实现包 |
| Controller → Mapper | **无**（`/auth/me` 已下沉 Service） |
