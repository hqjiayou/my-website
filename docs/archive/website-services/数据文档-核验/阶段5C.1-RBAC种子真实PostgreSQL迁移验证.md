## 5. admin_role 验证结果

```sql
SELECT role_code, role_name, status, deleted
FROM admin_role
WHERE role_code IN ('super_admin', 'admin')
ORDER BY role_code;
```

| role_code | role_name | status | deleted |
|-----------|-----------|--------|---------|
| admin | 系统管理员 | ACTIVE | false |
| super_admin | 超级管理员 | ACTIVE | false |

- 共 **2** 行，符合 V2 种子设计。
- **`super_admin`** 无 `admin_role_permission` 绑定（Checker 短路，不依赖表内绑定）。

## 6. admin_permission 验证结果

- **ACTIVE 且未删除** 权限行数：**16**（**5C.2** 起不含测试探针 `admin:rbac:check`）
- 权限码均为小写 `admin:{domain}:{action}` 格式。
- 覆盖 5C 生产种子：`admin:role:*`、`admin:permission:list`、`admin:user:*`、`admin:menu:view`、`admin:site:*`、`admin:dashboard:view`。

`resource_type`：`ACTION` 15 条，`MENU` 1 条（`admin:menu:view`）。

## 7. admin_role_permission 验证结果

- **`admin` 角色** 绑定 **16** 条 ACTIVE 权限（与 `admin:%` 生产种子一致，不含 `admin:rbac:check`）。
- **`super_admin` 角色** 绑定数：**0**（符合设计）。

抽样 SQL（与 5C 任务书一致）：

```sql
SELECT r.role_code, p.permission_code
FROM admin_role_permission rp
JOIN admin_role r ON r.id = rp.admin_role_id
JOIN admin_permission p ON p.id = rp.admin_permission_id
WHERE r.role_code = 'admin' AND rp.deleted = FALSE
ORDER BY p.permission_code;
```
