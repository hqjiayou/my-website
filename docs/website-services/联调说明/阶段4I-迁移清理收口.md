# 阶段 4I：迁移清理收口

> **文档状态**：收口结论（文档与脚本口径对齐，无业务功能变更）  
> **前置**：**4F** 主链路上提、**4G** RS256+JWKS、**4H** Gateway 唯一入口联调均已关闭  
> **最近同步**：2026-05-17  

---

## 1. 阶段目标

在认证迁移与网关收口已稳定的前提下，做 **低风险收尾**：

- 清除 **脚本/注释** 中仍暗示 **旧对称密钥（如 Admin `SECURITY_JWT_SECRET`）** 或过时代码路径的表述（**4G 后主链路已 JWKS**）。
- **路线图、总览、`services` README** 与 **4H 事实**一致，避免「4H 未完成」「RBAC 仍等 4H」等过时口径。
- **不**重构 RS256/JWKS、**不**改 Resource Server、`gateway` **不**新增 JWT 业务校验。

## 3. 4I 关闭标准

| 验收项 | 要求 |
|--------|------|
| 误导性配置提示已消除 | 本地/CI 脚本不因过时密钥名误导运维 |
| 文档自洽 | 路线图、总览、4D §十二、架构设计「近期」与 **4H 完成 + 4I 收口** 一致 |
| 构建 | `services/website-services` 下 `mvn -DskipTests validate`、`mvn test` 通过（有代码/脚本改动时执行） |

---

## 4. 结论

**阶段 4I 可正式关闭** 当且仅当上表验收满足。关闭后，**下一阶段默认推进 5A（Admin RBAC 深化）**；若排期另有优先级，仍以 [`后端开发路线图与阶段状态`](../总览/后端开发路线图与阶段状态.md) 为准。
