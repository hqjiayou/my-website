# 阶段 4I：认证阶段迁移清理收口

> **文档状态**：当前有效  
> **前置**：**4F** 主链路上提、**4G** RS256+JWKS、**4H** Gateway 全链路联调、**4H.0** 可观测与 Token 错误体  
> **最近同步**：2026-05-20  
> **下一阶段**：**5A Admin RBAC 权限体系详细设计**

---

## 1. 阶段目标

认证阶段在功能上已于 **4H** 验收；**4I** 做 **低风险收尾**，使 **代码、配置、脚本、文档** 与现行事实一致，然后 **正式结束认证阶段**，进入权限阶段。

**不做**：RS256/JWKS 重构、Gateway JWT 验签、RBAC 业务、库表/Flyway 变更。

---

## 2. 4H 联调暴露项（已收口）

| 项 | 问题 | 处理 |
|----|------|------|
| **run-4h Redis 观测** | `redis-cli` 未带密码 → `NOAUTH` | 脚本从 **`website-services/.env`** 或环境变量读取 **`REDIS_PASSWORD`**，`docker exec … redis-cli -a … --no-auth-warning` |
| **X-Request-Id 重复** | Gateway 与下游 Servlet 各写响应头 | Gateway **仅在 `doFinally` 写一次**；Servlet **入站已带 X-Request-Id 时不再回写**（直连仍回写） |

---

## 3. 认证 HTTP 路径（4I 后唯一主路径）

| 语义 | 路径 |
|------|------|
| 登录 | `POST /api/auth/admin/login` |
| 刷新 | `POST /api/auth/admin/refresh` |
| 登出 | `POST /api/auth/admin/logout` |
| 注册（bootstrap） | `POST /api/auth/admin/register` |

**已删除兼容别名**（4I 不再保留）：

- ~~`POST /api/auth/token/refresh`~~
- ~~`POST /api/auth/logout`~~

**禁止再作对外契约的旧编排前缀**（仅 4C 历史文档归档中保留说明）：

- ~~`POST /api/admin/auth/login|refresh|logout`~~

**仍为现行、非旧口径**：

- `GET /api/admin/auth/me` — Admin **业务上下文**（Resource Server），不是 auth 编排。

---

## 4. Refresh Cookie 与配置（现行事实）

| 属性 | 本地默认 | 说明 |
|------|----------|------|
| 名称 | `MYWEBSITE_REFRESH_TOKEN` | `mywebsite.security.token.refresh-cookie-name` |
| **Path** | **`/api/auth/admin`** | 覆盖 admin 登录/刷新/登出同前缀 |
| **HttpOnly** | `true` | |
| **SameSite** | **`Lax`** | 非 Strict；生产可按策略改为 Strict |
| **Secure** | 本地 `false`（`SECURITY_REFRESH_COOKIE_SECURE`） | 生产建议 `true` |

历史文档中的 **SameSite=Strict**、**Path=/api/auth/token/refresh** 已按 4I 清扫为归档表述或更新为上行。

---

## 5. i18n 与成功响应

- **成功**：统一 **`message = "success"`**（`ResponseMessages.SUCCESS`），**不**走 i18n。
- **已删除未使用 key**（4I）：
  - `auth.admin.login.success`
  - `auth.token.refresh.success`
  - `auth.logout.success`
- **保留**：`admin.auth.*` 错误 key、`auth.site.login.not-implemented`（Site 占位）。

---

## 6. 模块边界终审

| 模块 | 职责 | 4I 确认 |
|------|------|---------|
| **gateway** | 路由、CORS、RequestId、访问日志 | **不**做认证业务、**不**验签 JWT |
| **auth** | 唯一认证编排、JWT 签发、Refresh 会话、JWKS | **不**依赖 admin 业务 jar |
| **admin** | Resource Server + 后台业务（含 `/api/admin/auth/me`） | **无** login/refresh/logout 编排 |
| **common** | 协议、ErrorCode、Token 配置、RequestId 常量 | |
| **infra** | Servlet 日志、i18n、OAuth2 RS 辅助 | |
