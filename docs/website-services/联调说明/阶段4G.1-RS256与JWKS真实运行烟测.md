# 阶段 4G.1：RS256 与 JWKS 真实运行烟测

> **文档状态**：烟测记录（运行时验收）  
> **最近同步**：2026-05-17  
> **依赖**：阶段 4G 代码与配置（RS256 签发、JWKS、`jwk-set-uri` 验签）

---

## 1. 目标

在多进程、真实监听端口下验证最小闭环：

1. **Auth** 对外提供 **`GET /.well-known/jwks.json`**（合法 JWK Set，公钥-only）。  
2. **Auth** **`POST /api/auth/admin/login`** 签发 **RS256** Access Token（Header 含 **`kid`**）。  
3. **Admin** 仅凭 **`AUTH_JWKS_URI`** 拉取 JWKS 并完成 **`GET /api/admin/ping`** 验签，**不依赖** `SECURITY_JWT_SECRET`。  
4. **负向**：非法 Bearer → **401**。

本轮**不经 Gateway**，与 4H 全链路联调分离。

---

## 2. 环境准备

| 组件 | 说明 |
|------|------|
| PostgreSQL | 本机已有容器 **`local-postgres`**（`localhost:5432`，库 **`my_website_dev`**，用户与本文 `.env` 对齐）。 |
| Redis | 本机已有容器 **`local-redis`**（`localhost:6379`，与本机 `.env` 口令一致）。 |
| RSA PEM | 按 [`scripts/local/README-4G-jwks.md`](../../../services/website-services/scripts/local/README-4G-jwks.md) 生成至 **`services/website-services/secrets/local/`**（**勿提交**）。 |
| 联调账号 | 已存在用户 **`admin_local_verify`** / 密码 **`Local4c_Verify`**（见 [`seed-admin-local-verify.sql`](../../../services/website-services/scripts/local/seed-admin-local-verify.sql)）。 |

**说明**：本地基础设施统一为 **local-stack**（本仓库不再附带第二套 Postgres/Redis Compose）。烟测在**已运行的 `local-postgres` / `local-redis`** 上完成。

---

## 3. RSA PEM 与 `.env`（烟测时）

在 **`services/website-services/`** 维护 `.env`（不入库），至少包含：

- `AUTH_JWT_PRIVATE_KEY_PATH` / `AUTH_JWT_PUBLIC_KEY_PATH` / `AUTH_JWT_KEY_ID`  
- `AUTH_JWKS_URI=http://localhost:8083/.well-known/jwks.json`  
- 与当前 Postgres/Redis 一致的 **`POSTGRES_*` / `REDIS_*`**

---

## 4. 启动命令（示例）

在仓库根或 **`services/website-services`** 下，若 Shell 中曾注入错误的 **`DB_USERNAME=...` / `DB_PASSWORD=CHANGE_ME`**（与 Docker 账号不一致），**`LocalDotenv` 不会覆盖已有 OS 环境变量**，会导致 Auth **DB 健康检查 DOWN、Login 返回系统错误**。烟测前在 PowerShell 中执行：

```powershell
Remove-Item Env:DB_PASSWORD, Env:DB_USERNAME, Env:DB_URL -ErrorAction SilentlyContinue
```

再分别启动（需 two 终端或使用后台进程）：

```powershell
cd services/website-services
mvn -q -pl auth -am spring-boot:run "-Dspring-boot.run.jvmArguments=-Dserver.port=8083 -DAUTH_APP_PORT=8083"
mvn -q -pl admin -am spring-boot:run "-Dspring-boot.run.jvmArguments=-Dserver.port=8081"
```

若环境存在 **`SERVER_PORT`**（非 8083），需删除或使用上述 JVM 参数**显式固定 8083**，否则 **`AUTH_JWKS_URI`** 与实监听端口不一致会导致 Admin 验签失败。

---

## 5. 实测结果

### 5.1 JWKS endpoint

- **请求**：`GET http://localhost:8083/.well-known/jwks.json`  
- **HTTP**：200  
- **JSON**：合法 **JWK Set**，`keys.length >= 1`  
- **字段**：`kty=RSA`，`use=sig`，`alg=RS256`，`kid=auth-local-rs256-key-1`（与 `.env` 中 **`AUTH_JWT_KEY_ID`** 一致），含 **`n` / `e`**，**无** `d`、`p`、`q` 等私钥字段  

### 5.2 Login（RS256）

- **请求**：`POST http://localhost:8083/api/auth/admin/login`  
- **Body**：`{"username":"admin_local_verify","password":"Local4c_Verify"}`  
- **现行**：HTTP **200**，**`message`** + **`data.accessToken`**；Refresh Cookie 默认 **`MYWEBSITE_REFRESH_TOKEN`**，**`Path=/api/auth/admin`**，**`SameSite=Lax`**。若历史备注仍写 **`code == 0`**，请以 **`services/website-services/README.md`** §认证 HTTP 契约为准。
- **Access Token 首段（JWT Header）解码**：`{"kid":"auth-local-rs256-key-1","alg":"RS256"}`（与 JWKS 中 **`kid`** 一致）。

### 5.3 Admin 经 JWKS 验签访问受保护接口

- **请求**：`GET http://localhost:8081/api/admin/ping`  
- **Header**：`Authorization: Bearer <accessToken>`  
- **结果**：**HTTP 200**，业务 JSON 正常（如 `data.message` 为 admin 就绪信息）。  
- **说明**：Admin 日志中可在**首次**需解析 JWT 时观察到向 JWKS URI 拉取公钥的行为（具体文案依 Spring Security / Nimbus 版本而定）。

### 5.4 负向验签

- **构造**：随机篡改 Bearer 字符串（损坏 JWS 签名或载荷）  
- **请求**：同上 **`GET /api/admin/ping`**  
- **结果**：**HTTP 401**（符合预期）。

## 6. 配置核验（本轮结论）

| 检查项 | 结论 |
|--------|------|
| Admin 主配置无 **`SECURITY_JWT_SECRET`** | 已确认（YAML / 代码检索无此依赖）。 |
| Admin 使用 **`spring.security.oauth2.resourceserver.jwt.jwk-set-uri`** → **`AUTH_JWKS_URI`** | 是。 |
| Auth 依赖 PEM 路径 + **`AUTH_JWT_KEY_ID`** | 是（`application-local` + `AuthJwtKeyProperties`）。 |

## 7. 本轮发现的问题与修复（纳入仓库）

| 问题 | 修复 |
|------|------|
| 从 **`auth` 子模块目录**启动时，相对路径 `./secrets/local/...` 解析到 `auth/secrets/...`，文件不存在。 | **`RsaPemUtils`**：相对路径在 CWD 找不到文件时，**回退解析父目录**（`website-services`）。见 `auth/.../RsaPemUtils.java`。 |
| 本地 Redis **无密码**，默认占位 **`CHANGE_ME`** 会导致连接失败。 | **`auth/.../application-local.yml`**：`REDIS` password **默认空**（见 4G 轮次已合入）。 |
| **OS 级 `DB_*`** 与 Docker 账号冲突，Auth **DB DOWN**。 | 文档与 **`README-4G-jwks.md`** 补充：**清除冲突的 `DB_*` 或依赖 `POSTGRES_*`**。 |
