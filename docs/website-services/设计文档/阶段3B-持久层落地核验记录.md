## 4. 设计规范与仓库其它观测

| 观测点 | 说明 | 本轮是否修正 |
|--------|------|----------------|
| **`CurrentUserIdSupplier`** | `infra` 已提供接口；`AuditMetaObjectHandler` 使用 `ObjectProvider`，无 Bean 时不填充审计人 id，符合 §4.4 / §6 | 否（已满足） |
| **`@MapperScan`** | 仓库未显式使用；各 Mapper 带 `@Mapper`，且 `SpringBootTest` 可成功装载全部 Mapper Bean | 否（不属缺口） |
| **`auth` 无业务 Entity** | 未发现 `site` / `admin` 业务表 Entity 出现在 `auth` 模块 | 否（已满足） |
| **目录命名** | OpenAPI 等为 `XxxConfig`；业务包为 `controller` / `entity` / `mapper` 等，与既定规范一致 | 否 |
| **Gateway 聚合 Swagger** | `gateway/pom.xml` 当前 **无** `springdoc` / 聚合路由；与「持久层 3B」无直接依赖。若总体规划要求 8080 统一文档，应单独立项（非本轮 3B 范围） | 否 |
