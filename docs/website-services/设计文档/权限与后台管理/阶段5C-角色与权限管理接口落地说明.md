# 阶段 5C：角色与权限管理接口 + RBAC 种子

> **文档状态**：5C 已落地（角色 CRUD、权限只读、角色权限绑定、种子）。  
> **最近核对**：2026-10-10。5D、5E 只读也已落地；菜单写未做。

阶段 **5C** 在 **5B** 的 `AdminPermissionChecker` 与 Method Security 之上，落地 Admin 后台**角色管理**、**权限只读查询**、**角色-权限绑定**及生产 **RBAC 种子数据**。

---

## 1. 阶段目标

实现 Admin 后台角色与权限管理能力，包括：

- RBAC 基础角色 / 权限 **Flyway 种子**（仅数据，不改表结构）
- 角色列表 / 详情 / 创建 / 修改 / 软删除
- 权限列表 **只读** 查询
- 角色-权限绑定查询与 **替换式** 更新
- 全部接口 **Method Security** 保护
- 测试覆盖与文档自查

- **`super_admin`** 权限仍由 `AdminPermissionChecker` **短路**全部 `ACTIVE` 权限，不依赖 `admin_role_permission` 绑定。

## 3. 数据种子设计

### 3.1 Migration

| 文件 | 说明 |
|------|------|
| `services/website-services/infra/src/main/resources/db/migration/V2__seed_admin_rbac_permissions.sql` | 仅 **INSERT** 种子；**无** DDL |

### 3.2 角色种子

| role_code | role_name | 说明 |
|-----------|-----------|------|
| `super_admin` | 超级管理员 | Checker 短路；**禁止** API 创建 / 删 / 改码 / 改绑定 |
| `admin` | 系统管理员 | 绑定全部 `ACTIVE` 且 `permission_code LIKE 'admin:%'` 的权限 |

### 3.3 权限种子（首批）

格式：`admin:{domain}:{action}`，全小写；`resource_type` 为 `ACTION` 或 `MENU`。

| permission_code | resource_type | resource_key |
|-----------------|---------------|--------------|
| `admin:role:list` … `admin:role:permission:update` | ACTION | `role:*` |
| `admin:permission:list` | ACTION | `permission:list` |
| `admin:user:list` … `admin:user:role:update` | ACTION | `user:*` |
| `admin:menu:view` | MENU | `menu:view` |
| `admin:site:list` / `admin:site:detail` | ACTION | `site:*` |
| `admin:dashboard:view` | ACTION | `dashboard:view` |

生产种子共 **16** 条 ACTIVE 权限（**不含** `admin:rbac:check`；该码仅保留在 test scope，见 **5C.2**）。

幂等：`INSERT ... SELECT ... WHERE NOT EXISTS (... deleted = FALSE)`。

### 3.4 种子验证方式

- **CI / 默认 `mvn test`**：不启动 Flyway；Admin 集成测试使用 `admin/src/test/resources/rbac/rbac-h2-*.sql` 镜像语义。
- **真实 PostgreSQL（5C.1，已关闭）**：专用库 **`my_website_rbac_seed_verify`** + `AdminRbacSeedVerifyPgTest`（`verify-pg-rbac`）；详见 **[阶段5C.1-RBAC种子真实PostgreSQL迁移验证](../../数据文档/阶段5C.1-RBAC种子真实PostgreSQL迁移验证.md)**。
- **通用持久层 PG 流程**：见 [持久层真实PostgreSQL验证说明](../../数据文档/持久层真实PostgreSQL验证说明.md)。

## 4. 角色管理接口设计

基路径：`/api/admin/roles`（需 Bearer，`aud=ADMIN`）。

| 方法 | 路径 | 权限码 | 说明 |
|------|------|--------|------|
| GET | `/api/admin/roles` | `admin:role:list` | 列表；可选 `roleCode` / `roleName` / `status` |
| GET | `/api/admin/roles/{id}` | `admin:role:detail` | 详情 |
| POST | `/api/admin/roles` | `admin:role:create` | 创建；`role_code` 必填唯一、`^[a-z][a-z0-9_]*$` |
| PUT | `/api/admin/roles/{id}` | `admin:role:update` | 改 `role_name` / `status` / `description`；**不可改** `role_code` |
| DELETE | `/api/admin/roles/{id}` | `admin:role:delete` | 软删除；已绑定用户 → 业务错误 |

业务规则：

- 禁止创建 `role_code = super_admin`
- 禁止删除 / 改码 `super_admin`
- 角色已绑定用户（`admin_user_role` 未删除）时禁止删除

## 5. 权限只读接口设计

| 方法 | 路径 | 权限码 | 说明 |
|------|------|--------|------|
| GET | `/api/admin/permissions` | `admin:permission:list` | 只读；可选 `permissionCode` / `resourceType` / `resourceKey` |

**无** POST / PUT / DELETE。

## 6. 角色-权限绑定接口设计

| 方法 | 路径 | 权限码 | 说明 |
|------|------|--------|------|
| GET | `/api/admin/roles/{id}/permissions` | `admin:role:permission:view` | 返回 `roleId`、`roleCode`、`permissions[]` |
| PUT | `/api/admin/roles/{id}/permissions` | `admin:role:permission:update` | 入参 `permissionCodes`；**替换式**更新 |

替换策略：现有绑定 **软删除** 后按新列表插入；未知 `permissionCode` → 业务错误；**禁止**修改 `super_admin` 绑定。

响应示例：

```json
{
  "message": "success",
  "data": {
    "roleId": 1,
    "roleCode": "editor",
    "permissions": ["admin:role:list", "admin:permission:list"]
  }
}
```

**缓存**：本阶段无用户权限 Redis 缓存；**5D 及以后** 若引入缓存，须在用户-角色 / 角色-权限变更时失效（本文档预留）。

## 7. Method Security 权限码

| 接口 | `@PreAuthorize` |
|------|-----------------|
| 角色列表 | `@adminPermissionChecker.hasPermission('admin:role:list')` |
| 角色详情 | `admin:role:detail` |
| 创建角色 | `admin:role:create` |
| 更新角色 | `admin:role:update` |
| 删除角色 | `admin:role:delete` |
| 权限列表 | `admin:permission:list` |
| 查看角色权限 | `admin:role:permission:view` |
| 更新角色权限 | `admin:role:permission:update` |

**禁止**在 `AdminSecurityConfig` 中按 URL 映射权限。

---

## 8. super_admin 保护策略

| 操作 | 行为 |
|------|------|
| 创建 `super_admin` | `400` + `admin.rbac.role.code.reserved` |
| 删除 `super_admin` | `400` + `admin.rbac.role.super-admin.immutable` |
| 修改 `super_admin` 的 `role_code` | 不适用（创建后不可改码）；更新其它字段亦拒绝 |
| 修改 `super_admin` 权限绑定 | `400` + `admin.rbac.role.super-admin.immutable` |
| 运行时鉴权 | `AdminPermissionChecker` 对 `super_admin` 角色 **短路通过** |

实现：`AdminRoleGuard` + 各 Service 入口校验。
