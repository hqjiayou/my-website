## 1. 目标与边界

| 项 | 说明 |
|----|------|
| **目标** | 后台侧栏 MENU 树数据模型、种子、为 `/api/admin/auth/me` 的 `menus` 与菜单 CRUD API 提供库表基础 |
| **模块** | 仅 **admin**；auth / gateway / common 不改 |
| **不建表** | 无 `admin_menu`、无 `role_menu` |
| **菜单存储** | `admin_permission` 且 `resource_type = 'MENU'` |
| **可见性** | 角色通过 **`admin_role_permission`** 绑定 MENU 型 `permission_id`（与 5C 一致） |
| **Entity** | 仅扩展 **`AdminPermissionEntity`**；**不新增** `AdminMenuEntity` |

## 2. V3 结构扩展（`admin_permission`）

| 列 | 类型 | 非空 | 默认 | 用途 |
|----|------|------|------|------|
| `parent_id` | `BIGINT` | 否 | `NULL` | MENU 父节点；FK → 本表 `id` |
| `sort_order` | `INTEGER` | 是 | `0` | 同级排序 |
| `route_path` | `VARCHAR(255)` | 否 | `NULL` | 前端路由 → `AdminMenuNodeDto.path` |
| `icon` | `VARCHAR(128)` | 否 | `NULL` | 侧栏图标 |

**未纳入 V3**：`component`、`external_link`、`visible`、`keep_alive`（可见性用 **`status`**）。

**索引**：`idx_admin_permission_parent_active`、`idx_admin_permission_menu_tree_active`。

## 3. V4 种子数据

### 3.1 V2 占位处理

| permission_code | 处理 |
|-----------------|------|
| `admin:menu:view` | **`status = DISABLED'`**（保留行，不软删） |

### 3.2 MENU 树（`resource_type = MENU`）

| permission_code | permission_name | parent | sort | route_path | icon |
|-----------------|-----------------|--------|------|------------|------|
| `admin:menu:system` | 系统管理 | — | 10 | — | `setting` |
| `admin:menu:system.user` | 用户管理 | system | 10 | `/system/users` | `user` |
| `admin:menu:system.role` | 角色管理 | system | 20 | `/system/roles` | `team` |
| `admin:menu:system.permission` | 权限管理 | system | 30 | `/system/permissions` | `safety` |
| `admin:menu:system.menu` | 菜单管理 | system | 40 | `/system/menus` | `menu` |

### 3.3 菜单管理 ACTION（接口鉴权）

| permission_code | 用途 |
|-----------------|------|
| `admin:menu:list` | `GET /api/admin/menus` |
| `admin:menu:detail` | `GET /api/admin/menus/{id}` |
| `admin:menu:create` | `POST /api/admin/menus` |
| `admin:menu:update` | `PUT` / `PATCH .../status` |
| `admin:menu:delete` | `DELETE`（软删） |
| `admin:menu:sort` | `PUT /api/admin/menus/sort` |
| `admin:menu:bind` | `PUT /api/admin/menus/{id}/permissions`（可选 MVP） |

**分离原则**：`admin:menu:system.*` 为 **MENU**（可见性）；`admin:menu:list` 等为 **ACTION**（`@PreAuthorize`）。

### 3.4 `admin` 角色绑定

V4 §4 对 `role_code = 'admin'` 补绑所有新增 **`ACTIVE`** 且 `permission_code LIKE 'admin:%'` 的行（与 V2 策略一致）。

## 4. `/api/admin/auth/me` 与 `menus`（Java 待实现）

- **路径**：`GET /api/admin/auth/me`（非子路径 `/me.menus`）。
- **现状**：`AdminAuthMeDto.menus` 存在；`AdminAuthMeServiceImpl` 返回 **空列表**。
- **5E Java**：`AdminMenuService` 组树 → `AdminAuthMeServiceImpl` 填充 `menus`。
- **super_admin**：全部 ACTIVE 的 MENU 行；普通用户：权限码过滤后的 MENU 子集。

响应节点字段与 **`AdminMenuNodeDto`** 一致：`menuCode` ← `permission_code`，`menuName` ← `permission_name`。
