# Site 用户数据字典

本文档描述 **前台站点统一用户** 相关已落地表。用户按 **`site_id` 归属站点**（不用 `tenant_id`）；不按站点类型拆用户表。

**对应 Flyway**：`services/website-services/infra/src/main/resources/db/migration/V1__init_platform_core_tables.sql`

**未落地**：`site_user_auth`（多登录方式）暂不建表，后续认证阶段再评估。

---

## `site_user`

| 属性 | 说明 |
| --- | --- |
| **所属业务域 / 模块** | Site 前台用户（`site-core` / `site-app` 业务承载，DDL 由 admin Flyway 维护） |
| **表职责** | 前台登录主体之一：归属站点、用户名/邮箱/手机、密码哈希、状态；与 `admin_user` **隔离** |
| **主键策略** | `BIGINT GENERATED BY DEFAULT AS IDENTITY`，`id` |
| **多站点隔离** | **必填 `site_id`** → `site.id`；同一登录标识在不同站点可重复（跨站点不做全局唯一） |
| **软删除** | `deleted`；用户名/邮箱/手机唯一均在 **`deleted = FALSE`** 条件下且满足非空/trim 规则 |
| **公共审计字段** | 全量；触发器 `tr_site_user_touch_updated_at` |

### 字段清单

| 字段名 | 类型 | 非空 | 默认值 | 业务含义 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 是 | identity | 前台用户主键 |
| `site_id` | `BIGINT` | 是 | — | 所属站点，FK → `site.id` |
| `username` | `VARCHAR(128)` | 否 | — | 用户名；在同一站点未删除数据中唯一（非空且 trim 非空时参与唯一） |
| `email` | `VARCHAR(255)` | 否 | — | 邮箱；`(site_id, lower(email))` 在未删除且邮箱有效时唯一 |
| `phone` | `VARCHAR(32)` | 否 | — | 手机；`(site_id, phone)` 在未删除且手机有效时唯一 |
| `password_hash` | `VARCHAR(255)` | 否 | — | 密码哈希（若启用密码登录） |
| `status` | `VARCHAR(32)` | 是 | `'ACTIVE'` | `ACTIVE`、`DISABLED`、`LOCKED` 等 |
| `last_login_at` | `TIMESTAMPTZ` | 否 | — | 最近登录时间 |
| `created_at` | `TIMESTAMPTZ` | 是 | `now()` | 创建时间 |
| `created_by` | `BIGINT` | 否 | — | 创建人（如后台代建场景） |
| `updated_at` | `TIMESTAMPTZ` | 是 | `now()` | 更新时间 |
| `updated_by` | `BIGINT` | 否 | — | 更新人 |
| `deleted` | `BOOLEAN` | 是 | `FALSE` | 软删除 |
| `deleted_at` | `TIMESTAMPTZ` | 否 | — | 删除时间 |
| `version` | `INTEGER` | 是 | `0` | 乐观锁 |

### 唯一约束（partial unique）

| 名称 | 定义 |
| --- | --- |
| `uq_site_user_site_username_active` | `UNIQUE (site_id, username) WHERE deleted = FALSE AND username IS NOT NULL AND length(trim(username)) > 0` |
| `uq_site_user_site_email_active` | `UNIQUE (site_id, lower(email)) WHERE deleted = FALSE AND email IS NOT NULL AND length(trim(email)) > 0` |
| `uq_site_user_site_phone_active` | `UNIQUE (site_id, phone) WHERE deleted = FALSE AND phone IS NOT NULL AND length(trim(phone)) > 0` |

### 索引

| 名称 | 定义 |
| --- | --- |
| 同上 | 登录标识组合唯一 |
| `idx_site_user_site_id_active` | `(site_id) WHERE deleted = FALSE` |
| `idx_site_user_status_active` | `(status) WHERE deleted = FALSE` |

### 外键

| 约束名 | 引用 |
| --- | --- |
| `fk_site_user_site` | `site_id` → `site(id)`，`ON DELETE RESTRICT` |

### 与其他表关系

- **一对多**：一个 `site` 多个 `site_user`。
- **一对一扩展**：`site_user_profile.site_user_id` → 本表 `id`。

## `site_user_profile`

| 属性 | 说明 |
| --- | --- |
| **所属业务域 / 模块** | Site 前台用户资料 |
| **表职责** | 与认证字段解耦的展示与偏好信息：昵称、头像、性别、生日、语言、时区等 |
| **主键** | `BIGINT` identity |
| **多站点隔离** | **`site_id` NOT NULL**，与 `site_user.site_id` 对齐，便于按站点查询与 FK；业务上应与所属 `site_user` 的 `site_id` 一致 |
| **软删除** | 支持；**每个未删除用户最多一条 profile**（见唯一索引） |
| **公共审计字段** | 全量；触发器 `tr_site_user_profile_touch_updated_at` |

### 字段清单

| 字段名 | 类型 | 非空 | 默认值 | 业务含义 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 是 | identity | 资料行主键 |
| `site_id` | `BIGINT` | 是 | — | 冗余站点维度，FK → `site.id` |
| `site_user_id` | `BIGINT` | 是 | — | 所属用户，FK → `site_user.id` |
| `display_name` | `VARCHAR(255)` | 否 | — | 展示昵称 |
| `avatar_url` | `VARCHAR(1024)` | 否 | — | 头像 URL |
| `gender` | `VARCHAR(16)` | 否 | — | 性别 |
| `birthday` | `DATE` | 否 | — | 生日 |
| `locale` | `VARCHAR(32)` | 否 | — | 语言偏好 |
| `timezone` | `VARCHAR(64)` | 否 | — | 时区 |
| `created_at`…`version` | 公共字段 | — | — | 见 [平台与站点数据字典](./平台与站点数据字典.md#公共字段说明本批表统一约定) |

### 唯一约束

| 名称 | 定义 |
| --- | --- |
| `uq_site_user_profile_user_active` | `UNIQUE (site_user_id) WHERE deleted = FALSE` |

含义：同一 `site_user` 在未删除状态下仅允许一条 profile（含“曾删后重建”场景由软删除规则释放唯一槽位）。

### 索引

| 名称 | 定义 |
| --- | --- |
| `idx_site_user_profile_site_id_active` | `(site_id) WHERE deleted = FALSE` |

### 外键

| 约束名 | 引用 |
| --- | --- |
| `fk_site_user_profile_site` | `site_id` → `site(id)`，`ON DELETE RESTRICT` |
| `fk_site_user_profile_user` | `site_user_id` → `site_user(id)`，`ON DELETE RESTRICT` |

### 与其他表关系

- **`site_user` 1 — 0..1 `site_user_profile`**（由应用与唯一约束共同保证）。

### 说明：双 FK（`site_id` + `site_user_id`）

- `site_user_id` 决定用户归属；`site_id` 与 `site` 的直接外键用于 **站点级查询、约束与权限范围**，并需与 `site_user.site_id` 一致（插入/更新应由应用层或后续 DB 约束保障一致性；当前未加跨列 check）。
