# Admin 认证授权数据字典

本文档描述 **后台管理 RBAC 与管理员账号** 相关已落地表。表结构已建，**本轮不实现登录、鉴权业务逻辑，不写入角色/权限种子数据**。

**对应 Flyway**：`services/website-services/infra/src/main/resources/db/migration/V1__init_platform_core_tables.sql`

**多站点说明**：Admin 体系为 **平台级**，表 **不含 `site_id`**，与前台 `site_user` 隔离。

---

## `admin_user`

| 属性 | 说明 |
| --- | --- |
| **所属业务域 / 模块** | Admin 后台账号（`admin` 应用） |
| **表职责** | 后台管理员登录主体：用户名、邮箱/手机、密码哈希、状态等 |
| **主键策略** | `BIGINT GENERATED BY DEFAULT AS IDENTITY`，`id` |
| **软删除** | `deleted`，唯一性采用 partial unique（见下） |
| **公共审计字段** | 含 `created_at`、`created_by`、`updated_at`、`updated_by`、`deleted`、`deleted_at`、`version` |
| **`updated_at`** | 触发器 `tr_admin_user_touch_updated_at` |

### 字段清单

| 字段名 | 类型 | 非空 | 默认值 | 业务含义 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 是 | identity | 管理员主键 |
| `username` | `VARCHAR(128)` | 是 | — | 登录用户名，未删除数据全平台唯一 |
| `email` | `VARCHAR(255)` | 否 | — | 邮箱；非空时在未删除数据内 `lower(email)` 唯一 |
| `phone` | `VARCHAR(32)` | 否 | — | 手机；非空且 trim 非空时在未删除数据内唯一 |
| `password_hash` | `VARCHAR(255)` | 否 | — | 密码哈希，明文不落库 |
| `display_name` | `VARCHAR(255)` | 否 | — | 展示名 |
| `status` | `VARCHAR(32)` | 是 | `'ACTIVE'` | 账号状态，如 `ACTIVE`、`DISABLED`、`LOCKED` |
| `last_login_at` | `TIMESTAMPTZ` | 否 | — | 最近登录时间 |
| `created_at` | `TIMESTAMPTZ` | 是 | `now()` | 创建时间 |
| `created_by` | `BIGINT` | 否 | — | 创建人 |
| `updated_at` | `TIMESTAMPTZ` | 是 | `now()` | 更新时间 |
| `updated_by` | `BIGINT` | 否 | — | 更新人 |
| `deleted` | `BOOLEAN` | 是 | `FALSE` | 软删除 |
| `deleted_at` | `TIMESTAMPTZ` | 否 | — | 删除时间 |
| `version` | `INTEGER` | 是 | `0` | 乐观锁 |

### 唯一约束（partial unique）

| 名称 | 定义 |
| --- | --- |
| `uq_admin_user_username_active` | `UNIQUE (username) WHERE deleted = FALSE` |
| `uq_admin_user_email_active` | `UNIQUE (lower(email)) WHERE deleted = FALSE AND email IS NOT NULL AND length(trim(email)) > 0` |
| `uq_admin_user_phone_active` | `UNIQUE (phone) WHERE deleted = FALSE AND phone IS NOT NULL AND length(trim(phone)) > 0` |

### 索引

| 名称 | 定义 |
| --- | --- |
| 同上 | 用户名 / 邮箱 / 手机唯一索引 |
| `idx_admin_user_status_active` | `(status) WHERE deleted = FALSE` |

### 外键与关联

- 无外键指向本表以外（角色通过 `admin_user_role`）。
- **被引用**：`admin_user_role.admin_user_id` → `admin_user.id`，`ON DELETE RESTRICT`。

## `admin_role`

| 属性 | 说明 |
| --- | --- |
| **所属业务域 / 模块** | Admin RBAC |
| **表职责** | 后台角色定义：编码、名称、状态 |
| **主键** | `BIGINT` identity，`id` |
| **软删除 / 审计** | 同首批公共约定；触发器 `tr_admin_role_touch_updated_at` |

### 字段清单

| 字段名 | 类型 | 非空 | 默认值 | 业务含义 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 是 | identity | 角色主键 |
| `role_code` | `VARCHAR(64)` | 是 | — | 角色编码，未删除全表唯一 |
| `role_name` | `VARCHAR(255)` | 是 | — | 角色名称 |
| `description` | `TEXT` | 否 | — | 说明 |
| `status` | `VARCHAR(32)` | 是 | `'ACTIVE'` | 角色状态 |
| `created_at`…`version` | 同公共字段 | — | — | 见平台站点字典「公共字段说明」 |

### 唯一约束

| 名称 | 定义 |
| --- | --- |
| `uq_admin_role_role_code_active` | `UNIQUE (role_code) WHERE deleted = FALSE` |

### 索引

| 名称 | 定义 |
| --- | --- |
| `idx_admin_role_status_active` | `(status) WHERE deleted = FALSE` |

### 外键与关联

- **被引用**：`admin_user_role.admin_role_id`、`admin_role_permission.admin_role_id` → `admin_role.id`，`ON DELETE RESTRICT`。

## `admin_permission`

| 属性 | 说明 |
| --- | --- |
| **所属业务域 / 模块** | Admin RBAC |
| **表职责** | 权限点：编码、名称、`resource_type` + `resource_key` 表达菜单/API/ACTION 等 |
| **主键** | `BIGINT` identity；触发器 `tr_admin_permission_touch_updated_at` |

### 字段清单

| 字段名 | 类型 | 非空 | 默认值 | 业务含义 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 是 | identity | 权限主键 |
| `permission_code` | `VARCHAR(128)` | 是 | — | 权限编码，未删除全表唯一 |
| `permission_name` | `VARCHAR(255)` | 是 | — | 权限名称 |
| `resource_type` | `VARCHAR(32)` | 否 | — | 资源类型：`MENU`（侧栏可见性）、`ACTION`（接口鉴权）等 |
| `resource_key` | `VARCHAR(255)` | 否 | — | 资源标识；MENU 行建议与编码后缀一致 |
| `description` | `TEXT` | 否 | — | 说明 |
| `status` | `VARCHAR(32)` | 是 | `'ACTIVE'` | 状态；`DISABLED` 表示停用（含旧版菜单占位行） |
| `parent_id` | `BIGINT` | 否 | `NULL` | **5E V3**：MENU 父节点 FK → `admin_permission.id`；根为 NULL |
| `sort_order` | `INTEGER` | 是 | `0` | **5E V3**：MENU 同级排序；非 MENU 行保持 `0` |
| `route_path` | `VARCHAR(255)` | 否 | `NULL` | **5E V3**：前端路由，映射 `/auth/me` 的 `menus[].path` |
| `icon` | `VARCHAR(128)` | 否 | `NULL` | **5E V3**：侧栏图标 key |
| `created_at`…`version` | 公共字段 | — | — | 同上 |

### 唯一约束

| 名称 | 定义 |
| --- | --- |
| `uq_admin_permission_code_active` | `UNIQUE (permission_code) WHERE deleted = FALSE` |

### 索引

| 名称 | 定义 |
| --- | --- |
| `idx_admin_permission_status_active` | `(status) WHERE deleted = FALSE` |
| `idx_admin_permission_parent_active` | **5E V3**：`(parent_id) WHERE deleted = FALSE` |
| `idx_admin_permission_menu_tree_active` | **5E V3**：`(resource_type, parent_id, sort_order) WHERE deleted = FALSE AND resource_type = 'MENU'` |

### 外键与关联

- **`fk_admin_permission_parent`**（**5E V3**）：`parent_id` → `admin_permission.id`，`ON DELETE RESTRICT`。
- **被引用**：`admin_role_permission.admin_permission_id` → `admin_permission.id`，`ON DELETE RESTRICT`。

### 5E 菜单种子（Flyway V4，摘要）

| permission_code | resource_type | 说明 |
| --- | --- | --- |
| `admin:menu:system` | MENU | 系统管理（根） |
| `admin:menu:system.user` / `.role` / `.permission` / `.menu` | MENU | 子菜单 |
| `admin:menu:list` … `admin:menu:bind` | ACTION | 菜单管理接口鉴权 |
| `admin:menu:view` | MENU | **V2 占位**；V4 置为 `DISABLED`，由 `admin:menu:system` 体系替代 |

菜单权限现行说明见 **[`../RBAC.md`](../RBAC.md)**（原《阶段5E-菜单权限与导航说明》已于 2026-10-29 移除，见 git 历史）。

## `admin_user_role`

| 属性 | 说明 |
| --- | --- |
| **所属业务域 / 模块** | Admin RBAC 关联 |
| **表职责** | 管理员与角色 **多对多**；防止同一用户重复绑定同一角色（未删除维度） |
| **主键** | `BIGINT` identity |
| **软删除** | 支持；重复绑定约束见 partial unique |

### 字段清单

| 字段名 | 类型 | 非空 | 默认值 | 业务含义 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 是 | identity | 关联行主键 |
| `admin_user_id` | `BIGINT` | 是 | — | 管理员 FK |
| `admin_role_id` | `BIGINT` | 是 | — | 角色 FK |
| `created_at`…`version` | 公共字段 | — | — | 全量审计字段与本批其他表一致 |

### 唯一约束

| 名称 | 定义 |
| --- | --- |
| `uq_admin_user_role_pair_active` | `UNIQUE (admin_user_id, admin_role_id) WHERE deleted = FALSE` |

### 索引

| 名称 | 定义 |
| --- | --- |
| `idx_admin_user_role_user_id` | `(admin_user_id) WHERE deleted = FALSE` |
| `idx_admin_user_role_role_id` | `(admin_role_id) WHERE deleted = FALSE` |

### 外键

| 约束名 | 引用 |
| --- | --- |
| `fk_admin_user_role_user` | `admin_user_id` → `admin_user(id)`，`ON DELETE RESTRICT` |
| `fk_admin_user_role_role` | `admin_role_id` → `admin_role(id)`，`ON DELETE RESTRICT` |

### 与其他表关系

- **多对多桥表**：连接 `admin_user` 与 `admin_role`。
