# 平台与站点数据字典

本文档描述 **平台级站点主数据** 相关已落地表。多站点隔离根为 `site`；行业类型（如 car/cake）通过 `site.site_type` 表达，**不引入 `tenant_id`**。

**对应 Flyway**：`services/website-services/infra/src/main/resources/db/migration/V1__init_platform_core_tables.sql`  
**PostgreSQL**：字段类型以 DDL 为准。

---

## `site`

| 属性 | 说明 |
| --- | --- |
| **所属业务域 / 模块** | 平台站点（Platform Site）；启动侧由 `admin` / `site-app` 共用同一 schema，数据由 Flyway 在 **admin** 执行演进 |
| **表职责** | 前台站点主数据：编码、名称、类型、状态、默认域名等；作为 `site_user`、`site_user_profile` 等站点级数据的隔离根 |
| **主键策略** | `BIGINT`，`GENERATED BY DEFAULT AS IDENTITY`，单列主键 `id` |
| **多站点隔离** | 本表 **不带 `site_id`**（自身即站点实体）；其他站点级业务表通过 `site_id` 引用本表 `id` |
| **软删除** | `deleted BOOLEAN NOT NULL DEFAULT FALSE`；物理删除不推荐；唯一性见下方 partial unique |
| **公共审计字段** | `created_at`、`created_by`、`updated_at`、`updated_by`、`deleted`、`deleted_at`、`version`（详见文末「公共字段说明」） |
| **`updated_at` 维护** | 触发器 `tr_site_touch_updated_at` → `fn_touch_updated_at()`，更新行时刷新为 `clock_timestamp()` |

### 字段清单

| 字段名 | 类型 | 非空 | 默认值 | 业务含义 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 是 | identity | 站点主键 |
| `site_code` | `VARCHAR(64)` | 是 | — | 站点编码，稳定、可读，用于配置与排查 |
| `site_name` | `VARCHAR(255)` | 是 | — | 站点展示名称 |
| `site_type` | `VARCHAR(32)` | 是 | — | 站点类型，如 `CAR`、`CAKE` |
| `status` | `VARCHAR(32)` | 是 | `'ACTIVE'` | 站点状态，如 `ACTIVE`、`DISABLED` |
| `default_domain` | `VARCHAR(255)` | 否 | — | 默认访问域名；多域名后续可拆 `site_domain` |
| `description` | `TEXT` | 否 | — | 站点说明 |
| `created_at` | `TIMESTAMPTZ` | 是 | `now()` | 创建时间 |
| `created_by` | `BIGINT` | 否 | — | 创建人（管理员用户 ID 等），系统任务可为空 |
| `updated_at` | `TIMESTAMPTZ` | 是 | `now()` | 最后更新时间（触发器刷新） |
| `updated_by` | `BIGINT` | 否 | — | 最后更新人 |
| `deleted` | `BOOLEAN` | 是 | `FALSE` | 软删除标记 |
| `deleted_at` | `TIMESTAMPTZ` | 否 | — | 软删除时间 |
| `version` | `INTEGER` | 是 | `0` | 乐观锁版本 |

### 唯一约束

| 名称 | 定义 | 说明 |
| --- | --- | --- |
| `uq_site_site_code_active` | `UNIQUE (site_code) WHERE deleted = FALSE` | 未删除行 `site_code` 全表唯一；已删除不占用唯一槽位 |

### 索引设计

| 名称 | 定义 | 用途 |
| --- | --- | --- |
| `uq_site_site_code_active` | 见上 | 唯一 + lookup |
| `idx_site_site_type_active` | `(site_type) WHERE deleted = FALSE` | 按类型筛选在线站点 |
| `idx_site_status_active` | `(status) WHERE deleted = FALSE` | 按状态筛选在线站点 |

### 外键与逻辑关联

- 本表无指向他表的外键。
- **被引用**：`site_user.site_id`、`site_user_profile.site_id` 等 → `site.id`，`ON DELETE RESTRICT`。

### 与其他表的关系

- **一对多**：一个 `site` 对应多条 `site_user`；`site_user_profile` 通过 `site_user` 间接归属站点，且冗余 `site_id` 便于按站点过滤（与 FK 并存）。

## 公共字段说明（本批表统一约定）

以下字段在首批各业务表中语义一致（具体是否非空以各表 DDL 为准）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `created_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | 插入时间 |
| `created_by` | `BIGINT` | 操作者 ID，可空 |
| `updated_at` | `TIMESTAMPTZ NOT NULL DEFAULT now()` | 更新时间；各表 `BEFORE UPDATE` 触发器写入 `clock_timestamp()` |
| `updated_by` | `BIGINT` | 操作者 ID，可空 |
| `deleted` | `BOOLEAN NOT NULL DEFAULT FALSE` | 软删除：`FALSE` 表示有效 |
| `deleted_at` | `TIMESTAMPTZ` | 软删除时刻，有效数据通常为 NULL |
| `version` | `INTEGER NOT NULL DEFAULT 0` | 乐观锁，递增策略由应用层后续定义 |
