# 阶段 5D.1 — Admin RBAC 包结构收敛

## 目标

删除 **`com.mywebsite.admin.rbac`** 功能域包，RBAC 相关类回归 **`admin` 模块标准分层**（`controller` / `dto` / `mapper` / `service` / `security` / `constant`），与 `AdminPingController`、`AdminAuthMeController` 等同构。

## 约束（未改动）

| 项 | 状态 |
|----|------|
| HTTP URL / 请求体 / 响应体 | **未改** |
| RBAC 业务逻辑 | **未改** |
| `@PreAuthorize` 权限码 | **未改** |
| Flyway / 数据库 | **未改** |
| Auth / Gateway | **未改** |

仅调整：**`package` 声明**、**`import`**、测试 **`package`/`import`**、文档路径说明。

## 最终包结构（RBAC 相关）

```text
com.mywebsite.admin
├── constant
│   ├── AdminRbacConstants.java
│   └── AdminRbacMessageKeys.java
├── controller
│   ├── AdminRoleController.java
│   ├── AdminPermissionController.java
│   └── AdminUserRoleController.java
├── dto
│   └── AdminRbacDtos.java          # 仅 HTTP 契约（快照见 security.AdminCurrentAuthorizationSnapshot）
├── mapper
│   ├── AdminRbacQueryMapper.java
│   ├── AdminRoleManagementMapper.java
│   └── AdminUserRoleManagementMapper.java
├── service
│   ├── AdminRoleGuard.java
│   ├── AdminPermissionQueryService.java
│   └── …ManagementService + impl/
├── security
    ├── AdminPermissionChecker.java
    ├── CurrentAdminAuthorizationHolder.java
    └── AdminCurrentAuthorizationSnapshot.java
```

**已删除**：`com.mywebsite.admin.rbac`（含 `rbac/controller`、`rbac/dto`、`rbac/mapper`、`rbac/service`、`rbac/security`、`rbac/support`）。

**保留（非 Java 包）**：`admin/src/test/resources/rbac/rbac-h2-*.sql`（`@Sql("/rbac/...")` 路径不变）。

## Config 小收敛（Method Security 并入安全配置）

| 变更 | 说明 |
|------|------|
| **删除** `AdminMethodSecurityConfig.java` | 不再单独占一个 `@Configuration` |
| **合并** `@EnableMethodSecurity` | 标注在 `AdminSecurityConfig`（与 `@EnableWebSecurity` 同文件） |
| **清理** `AdminSecurityConfig` 未使用 import | 移除 `AdminAccessDeniedHandler`、`AdminAuthenticationEntryPoint`、`HttpMethod`（EntryPoint/AccessDenied 仍通过方法参数注入，类型为接口） |

**未改动**：`SecurityFilterChain` 规则、`adminJwtAuthenticationConverter`、`AdminJwtDecoderConfig`、`AdminOpenApiConfig`。

## 常量收敛（test-only 权限码移出 main）

| 变更 | 说明 |
|------|------|
| **移除** `AdminRbacConstants.PERMISSION_RBAC_CHECK` | `admin:rbac:check` 仅 test 使用，不再出现在 main |
| **test** `RbacTestController` | `private static final PERMISSION_RBAC_CHECK`，`@PreAuthorize` 通过编译期常量拼接引用 |
| **test** `AdminPermissionCheckerTest` | 同类私有常量，替代对已删 main 常量的引用 |
| **保留** `ROLE_SUPER_ADMIN` | main 继续使用 |
| **保留** `STATUS_ACTIVE` | 用于 `AdminRbacQueryMapper`、各 RBAC Service/Impl 与 `AdminPermissionQueryServiceImpl`（用户状态过滤）；**待办**：后续若全模块统一状态枚举，再收敛为 `CommonStatus` / `RecordStatus`，**本轮不扩大** |

**未改动**：Flyway 种子、HTTP 接口、RBAC 判权逻辑；H2 测试数据 `rbac-h2-data.sql` 仍含 `admin:rbac:check` 行。

- **Method Security** 由 `AdminSecurityConfig` 统一启用（`@PreAuthorize` 行为不变）。
