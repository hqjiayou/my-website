## 四、已确认良好的部分

1. **`@SpringBootApplication(scanBasePackages = "com.mywebsite")`**（admin/site-app）：与 MyBatis **`@MapperScan`**、多模块 Bean 共存策略一致（需注意扫描面偏大带来的 **无意 Bean 冲突** 风险，属长期纪律问题）。
2. **`AbstractAuditableEntity`**：字段与 Flyway 首批表对齐；时间列交由库默认值 + 触发器，注释说明与 **`AuditMetaObjectHandler`** 职能边界清晰。
3. **`AuditMetaObjectHandler`**：仅填充 `created_by`/`updated_by`，实现简短。
4. **`CurrentUserIdSupplier`**：**可选 SPI**，无 Bean 时审计人字段跳过填充——适合 4B 接入登录上下文。
5. **持久层 PG 回归**：`AdminUserPersistenceVerifyPgTest` / `SitePersistenceVerifyPgTest` + **`persistence-verify-pg`** Profile + **`verify-pg`** YAML，链路闭环文档化程度高。
6. **网关**：依赖精简（Gateway + Actuator），符合「不直连 DB/Redis」约束。
