## 已完成

- **基础架构**：Maven 多模块、`gateway` / `auth` / `admin` / `site-app` 可启动；**Gateway :8080** 为统一入口（**4H** 已实机联调 Login / Bearer / Refresh / Logout）  
- **数据库初始模型**：Flyway V1、[`数据库模型设计V1`](../设计文档/数据与持久层/数据库模型设计V1.md)、[`docs/数据字典`](../../数据字典/)  
- **持久层基础**：MyBatis-Plus、首批 Entity/Mapper、3C PostgreSQL 验证文档  
- **Admin 认证（最终形态在 4F）**：**HTTP 与 Refresh 会话在 `auth`**；**admin** 仅 Resource Server  
- **后端系统消息国际化**：infra 底座 + 各模块 `i18n` bundle  
- **Auth 单服务收敛（4F）**：单一 **`auth`** 模块、Gateway **`/api/*/auth/**`**、移除 **auth-core/auth-app** 与顶层 **config**  
- **RS256 + JWKS（4G）**：Auth 私钥签发 Access JWT、**`GET /.well-known/jwks.json`**；Admin 仅 **`spring.security.oauth2.resourceserver.jwt.jwk-set-uri`** 验签，**不持有**签名密钥  
- **4H.0 可观测与 401 一致性**：**Gateway / Auth / Admin（及 site-app）** 支持统一 **`X-Request-Id`** 与 **INFO 访问日志**；Auth 主流程 **安全事件日志**；Bearer 无效时 **`auth.token.invalid`** + **`WWW-Authenticate: invalid_token`**（[**阶段4H.0**](../设计文档/认证与安全/阶段4H.0-请求链路日志与Token错误响应完善说明.md)）  
- **4H Gateway 全链路联调**：**`8080`** 为推荐外部入口；路由 **`/api/auth/**` → Auth**、**`/api/admin/**` → Admin**；脚本 [**`run-4h-gateway-auth-flow-verify.ps1`**](../../../services/website-services/scripts/local/run-4h-gateway-auth-flow-verify.ps1)；说明 [**阶段4H**](../联调说明/阶段4H-Gateway唯一入口全链路真实联调.md)  
- **文档体系重整**：`docs/website-services/README.md`、`总览/`、设计文档分盘
- **4I 认证阶段收口**：删除 **`/api/auth/token/refresh`**、**`/api/auth/logout`** 兼容；**`X-Request-Id`** 经 Gateway 单头；**run-4h** Redis 带密码；Cookie **`SameSite=Lax`** / **`Path=/api/auth/admin`** 文档与代码一致（[**阶段4I**](../联调说明/阶段4I-迁移清理收口.md)）
