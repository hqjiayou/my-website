## 1. 定位

本工程是 **多模块 Spring Boot 后端**：**统一网关入口**，**认证与业务进程分离**，**共享库契约**（`common`、`common.security`）与 **基础设施**（`infra`）下沉复用。

---

## 2. 运行时组件（与端口）

| 进程 | 模块 | 默认端口 | 职责摘要 |
|------|------|----------|----------|
| **Gateway** | `gateway` | 8080 | **唯一对外 HTTP 入口（架构意图）**；按路径拆分路由，**不**做业务逻辑、**不**直连库与 Redis |
| **Auth** | `auth` | 8083（`AUTH_APP_PORT`） | **唯一统一认证服务**；**`/api/auth/*`** 编排（Login / Refresh / Logout），Access JWT（**RS256**）、Refresh Cookie、**Redis** 刷新会话；**不设 Flyway**（与 admin 共库时由 admin 迁移） |
| **Admin** | `admin` | 8081 | **OAuth2 Resource Server** + 后台 **业务 API**；**不**再承载认证主链路 HTTP |
| **Site** | `site/site-app` | 8082 | 前台站点 API；**当前**探活与骨架为主；**未来**多门户、多行业站点共用 **site-core** 基础能力 |
| （可选）Agent 客户端 | `agent` | — | 被 `admin` / `site-app` 依赖；编排调用外部 **agent-services**，不直接扛业务库 |

**Gateway 路由（当前事实）**

- **`/api/auth/**`** → **Auth（8083）**  
- **`/api/admin/**`** → **Admin（8081）**（业务 API，含 **`GET /api/admin/auth/me`**；需 Bearer）  
- **`/api/site/**`** → **Site（8082）**（含 **`GET /api/site/auth/me`**）  

**顺序**：`/api/auth/**` 须在 **`/api/admin/**`、`/api/site/**`** 之前。
---

## 3. 库模块（不单独对外端口）

### common

跨模块 **协议外壳**：`ApiResponse`、`ErrorCode`、`BusinessException`、`PageResult`；**`com.mywebsite.common.security`**：`JwtClaimConstants`、`SubjectType`、`SubjectCodes`、`TokenAudience`、`AuthenticatedUser`、`AuthContext` 等 **轻量 JWT/身份契约**（Resource Server 与调用方对齐）。

### infra

**技术基础设施**：数据源、Redis、MinIO；**MyBatis-Plus** 全局插件与 **`AbstractAuditableEntity`**；**系统消息 i18n**（`Accept-Language`、`LocalizedMessageService`）；**`JwtSecretPresentCondition`**（对称 JWT 条件装配，**包名：`com.mywebsite.infra.jwt.JwtSecretPresentCondition`**）。**不**写业务用例。

### agent

对外 **AI/Agent** 的 Java 客户端骨架；不替代 `admin`/`site` 编排。

### site（聚合）

- **site-core**：站点上下文、站点用户等 **前台域** 基础（**未来**多门户扩展的共享内核）。  
- **site-car / site-cake**：行业模块骨架。  
- **4F** 尚未做多门户进程级拆分；文档与包结构 **预留** 扩展空间。

---

## 4. 认证链路（现行）

1. 客户端经 **Gateway** 访问 **`/api/auth/*`**（如 **`POST /api/auth/admin/login`**）→ **Auth** 完成凭证校验、签发 Access JWT（**`subject_type`：`SubjectType`**）、维护 Refresh **Rotation / Replay** 与 **Redis** 会话。  
2. 业务请求 **`/api/admin/**`** / **`/api/site/**`** → **Admin** / **Site-app**，**校验 Bearer**（Resource Server）。  
3. **4G**：**RS256 + JWKS**；业务服务 **`jwk-set-uri`** 验签。**路径清单**：**[`README`](../../services/website-services/README.md)** §认证 HTTP 契约。
