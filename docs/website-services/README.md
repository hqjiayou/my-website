## 当前后端整体定位（一句话）

**`gateway`** 为统一入口；**`auth`** 为**唯一、独立启动**的统一认证服务（Admin 登录/刷新/登出）；**`admin`** 为 **Resource Server + 后台业务**；**`common` / `infra`** 为共享协议与基础设施；**`site`** 为前台业务域（未来多门户共用基础能力）。**JWT：HS256 + 共享 secret 为 4F～4G 过渡；4G 目标 RS256 + JWKS。**
