# admin-web 设计规范

> 状态：草案 v1（2026-10-30，Issue #148 UoW-1）。现状实测分析见 Issue #148 的盘点结论；本文的数值与 theme.css／组件实现冲突时以本文为准修订代码。标注「待拍板」的三处以建议值暂填，拍板后改一处即定稿。

> 参考系：**shadcn/ui 的 token 体系**（本仓 token 命名正源于此）与 **Ant Design 后台的尺寸共识**（侧栏 200–256、顶栏 64、4px 间距基准）。

## 0. 设计定调

四个关键词：**克制、扁平、数据优先、低对比分隔**。

- 色彩克制：界面以无彩色（slate 灰阶）为骨，主色只用于主操作、激活态与链接；状态色只表达状态，不作装饰。
- 扁平：内容卡片只用 1px 边框、不用阴影；阴影只属于浮层（下拉、抽屉、弹窗、toast），按 z 轴分三级。
- 数据优先：表格与表单是主角，密度三档（compact/default/comfortable）服务于「一屏看多少数据」的选择，而不是装饰性留白。
- 与参考系的关系：token 命名与分层学 shadcn（语义色 + CSS 变量 + 深色成对），布局尺寸学 Ant Design 后台共识，视觉气质对齐 Linear/Vercel 式低对比扁平——三者本就同源，不打架。

## 2. 颜色 Token 体系 v2

现状 8 个（background/foreground/card/card-muted/border/muted-foreground/primary/primary-foreground）不够用，导致页面借 rose/slate 原生色与硬编码 hex 补位。目标全表（浅色值沿用现有 slate/blue 色板逻辑，深色成对给出；RGB 三元组制式不变）：

**表面与文字（现有，保留）**：`--background`、`--foreground`、`--card`、`--card-muted`、`--border`、`--muted-foreground`。
**补齐（对齐 shadcn 缺口）**：
- `--popover` / `--popover-foreground`：下拉、浮层专用面（现借用 card，浮层与卡片同色在深色下分不开）；
- `--secondary` / `--secondary-foreground`：次级按钮的语义底（现 secondary 按钮是 border+card 手工拼的）；
- `--accent` / `--accent-foreground`：hover/选中浅底（菜单与列表 hover 现借 card-muted，可保留映射 accent=card-muted 起步，但要有名分）；
- `--input`：输入框边框专用（现与 border 共用，聚焦前后的边框层级分不开时再启用，先登记）；
- `--ring`：聚焦环专用色（= primary 28% 透明的成文形式，终结各处手写 `rgb(var(--primary)/x)` 与 `--admin-primary` 笔误）；
- `--sidebar` / `--sidebar-foreground` / `--sidebar-accent`：侧栏专属（现侧栏与内容同面，补名分，深色下可与内容面拉开半档）。

**状态色（新增，各含 base / foreground / muted-bg 三值，浅深成对）**：
- `--danger`（red-600 浅 / red-400 深）、`--success`（emerald-600 / 400）、`--warning`（amber-600 / 400）、`--info`（sky-600 / 400）。
- 使用规则：状态标签＝muted-bg（base 的 10–12% 透明）+ base 深一档文字；状态按钮（danger）＝base 底 + 白字（浅色）/ 深底亮字（深色）；**禁止再直接写 rose/emerald/amber 的 Tailwind 类**。
- 对比验收线：任何「文字色×其底色」组合 ≥ 4.5（正文）/ ≥ 3.0（大字与图标），新 token 落地时逐项验算并把结果记在 theme.css 注释里。

**深色修正（修分析 B-2）**：`.dark` 补 `--primary` 提亮至 blue-400（96 165 250，对深色卡面实测 5.75）；四个主色预设（蓝/紫/绿/橙）各自补深色值（同色相提亮一档）。

**图表色（登记备用）**：`--chart-1..5` 先占位（数据分析页在用色时按序取：蓝/紫/绿/橙/灰），避免将来各页自选图表配色。

**桥接**：`@theme inline` 补齐全部 token（含 card-muted、primary-foreground 与新增项），页面只用 Tailwind 语义类或 `.bg-admin-*` 语义类，**禁止任意值色与 hex**。

## 3. 间距阶梯

4px 基准，只许用阶梯值（Tailwind 默认刻度同源，成文约束用法）：

| 值 | 用途 |
|---|---|
| 4 | 图标与文字间、标签内 |
| 8 | 紧凑元素间（按钮组内、行内操作） |
| 12 | 菜单 item 内、卡片内小区块 |
| 16 | 表单字段纵距、卡片间纵距、工具栏内分组 |
| 20 | default 内容 padding、卡片内 padding（中档） |
| 24 | comfortable 卡片 padding、分区之间 |
| 32 | 页面大分区之间 |
| 40/48 | 空状态上下留白、登录等特殊页 |

禁止 `gap-3.5`、`p-[13px]` 之类阶梯外数值出现在页面里（组件内部实现细节除外，但须回到阶梯值）。

## 4. 布局壳规格

- 侧栏：展开 256 / 折叠 64（待拍板）；高度 100dvh 独立滚动；与内容面的分隔用 border，侧栏底色用 `--sidebar`（默认与 background 同值，靠边框区分）。
- 顶栏：高 64，sticky，底色 `--header-background`（现有的半透明+blur 保留），border-b；z-20。
- 内容：padding 随密度（14/20/28）；最大宽按骨架分工（待拍板）：数据页不限、设置/表单 1200 居中、文档 880。
- 响应式：≥lg 侧栏常驻；<lg 侧栏抽屉化（遮罩 z-40、抽屉 z-50），顶栏菜单按钮触发（现状已实现，成文）。
- **z-index 阶梯定案**：内容 0 / 顶栏 20 / 下拉与浮层菜单 30 / 遮罩 40 / 抽屉与弹窗 50 / toast 70。现状值正好成阶梯，补弹窗与 toast 两档后成文，页面禁止自创 z 值。

## 5. 侧边栏规格

- 品牌区：高 64 与顶栏对齐；产品名 text-base 600；kicker（10px 大写宽距）仅用于品牌区与分组眉题。
- 分组标题：12px、600、大写、tracking 0.12em、muted 色；组间距 24，组内 item 间距 4。
- 菜单 item：高随密度（32/36/40），图标 18，图标-文字 12，圆角 8，文字 14/500；hover＝accent 底；**激活态（待拍板）**：A 案现行实心主色 pill；B 案（建议）浅主色底（primary 12%）+ 主色文字 + 左 2px 指示条。折叠态只显图标，激活指示保留（B 案为底色块，A 案为整块主色）。
- 工作台二级导航（agentWorkspaceLayout 左栏）与主侧栏共用同一 item 规格（尺寸、激活态、分组标题全一致），禁止另写一套。

## 6. 顶部 Navbar 规格

- 左：折叠按钮（36 图标钮）+ 面包屑或当前页标题（二选一由壳层统一，现两处页头组件收编后只在内容区出现页头，顶栏不重复标题——定案：顶栏只放面包屑，页面标题在内容区 AdminPageHeader）。
- 中/右：搜索框宽 240（md 以上显示，聚焦环走 `--ring`；⌘K 命令面板列远期）、外观偏好入口、用户菜单（宽 200）。
- 图标按钮统一 36×36、圆角 8、hover accent 底；头像 32 圆形。

## 7. 控件规格

**尺寸三档**（高）：sm 28（行内操作、分页、标签旁按钮）／md 随密度 32/36/40（默认主力）／lg 44（页面主 CTA、弹窗确认）。圆角：sm 6 / md·lg 8。

**按钮五类 × 状态矩阵**（底／字／边框取 token，禁止原生色）：

| 类 | 静止 | hover | active | disabled |
|---|---|---|---|---|
| primary | primary 底 + on-primary 字 | 底 90% 透明 | 底 80% | 60% 透明、无指针 |
| secondary | card 底 + border + 主字 | accent 底 | card-muted 底 | 同上 |
| ghost | 透明 + 主字 | accent 底 | card-muted 底 | 40% |
| danger | danger 底 + 白字（补 md/lg 档，现仅 sm） | 底 90% | 底 80% | 60% |
| danger-ghost | 透明 + danger 字 + danger 边 | danger 浅底 | danger 浅底加深 | 40% |

- focus-visible 全类统一：2px `--ring` 外环 + 2px 偏移（终结逐处手写 ring 任意值）。
- loading：按钮内 spinner 16 替换图标、文字保留、禁点；提交中整表单字段不禁用（只禁提交钮），防闪烁。

**输入类**：输入框/选择器与 md 按钮同高同圆角；边框 `--input`（未启用时 border），focus＝主色边+ring；占位符 muted；禁用＝muted 底 + muted 字（现状已合，成文）。
**开关/复选/单选**（现无标准件，各页自写是高发不一致点，规格先行）：开关 36×20、圆点 16、开态主色底；复选/单选 16 方/圆、选中主色；文字与控件间距 8，整行可点。

## 8. 表单规范

- label 上置：12px/500、与字段间距 6；必填以 danger 色 `*` 后缀；帮助文字 12 muted 在字段下 4px；校验错误文字 12 danger 替换帮助位（不跳动：错误位预留一行高）。
- 字段纵距 16（comfortable 20）；双列只用于短字段（≥md 才分列，列距 16）。
- 弹窗表单（FormDialog）：宽阶梯 S 400 / M 560 / L 720；标题 16/600；内容 padding 20；底部操作区右对齐（取消 secondary + 确认 primary/danger），与内容以 border-t 分隔；危险确认弹窗确认钮用 danger、且文案写明对象名。
- 提交反馈：成功 toast + 关弹窗 + 列表刷新；失败保留输入、错误落字段或弹窗顶部 alert 区（二选一成文：字段级优先）。

## 9. 表格规格（DataTable 定案）

- 容器：圆角 12、border、无 shadow（按 §0 扁平定调，修现状 shadow-sm）；表头固定高 40（text-xs 大写、muted、card-muted 底）与行密度脱钩为有意决定。
- 行：高随密度 36/44/52；hover accent 底；选中行 primary 8% 底 + 左列复选 16；行操作列右对齐、sm 档 ghost/danger-ghost、间距 4，超过 3 个收进「更多」下拉。
- 列：文字左、数字右、状态居中用 StatusTag、时间列 tabular-nums；长文本截断 + title/展开（用 CopyableText 的场合在规范里点名：ID、URL、key 类字段）。
- 分页：右对齐，页码钮 28 方、圆角 6，当前页主色底；总数文案 12 muted 在左。
- 状态：加载＝骨架行（行高同密度档，3–5 行）；空＝组件内置空状态（图标 24 + 文案 + 可选主操作）；错误＝内置错误态（danger 图标 + 重试）。页面禁止自绘表格或自写空状态。

## 10. 卡片与 Item 规格

- 标准卡：圆角 12、border、card 底；padding 随密度 16/20/24；卡头＝16/600 标题 + 右侧操作（sm 钮），卡头与内容间距 12；卡片纵距 16。
- 统计卡（总览用）：数字 24/600 tabular-nums、标签 12 muted 在上、变化值用 success/danger 12 号带箭头图标 14。
- 列表 item（非表格场景，如账号列表）：行高最小 56，左图标/头像 36，主文 14/500 + 副文 12 muted，右状态或操作；分隔用 border，hover accent。
- 标签（StatusTag 定案）：高 22，圆角全 pill，字 12/500，底＝状态 muted-bg、字＝状态深一档；同一状态全站同色（状态→色映射表进规范附录，新增状态先登记）。

## 11. 反馈与浮层

- Toast（sonner）：右下，宽 ≤360；成功/失败/信息三态（图标+一句话，失败带「详情」展开或重试动作）；时长成功 3s、失败 5s 且可手动关；同类连发合并计数。位置与时长以现 Toaster 配置核对后定稿。
- 弹窗 z-50、遮罩 slate-900/40（现状值成文，深色同值）；抽屉右出宽 448（偏好）/560（详情编辑），动画 200ms ease-out。
- 页面内 alert 区（整页级错误/公告）：圆角 12、状态 muted-bg + 左 3px 状态条 + 14 文案，用于列表页顶部错误与系统公告，与 toast 分工（toast 管操作结果，alert 管页面状态）。

## 12. 图标

- 只用 lucide；尺寸阶梯：14（标签内/行内辅助）、16（按钮内、表单）、18（菜单）、20（卡头操作）、24（空状态、统计）。
- 图标颜色随文字色（currentColor），状态图标才用状态色；禁止同一含义换图标（语义映射进附录：如设置为 Settings、返回为 ArrowLeft，全站唯一）。
