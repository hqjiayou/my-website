# admin-web 设计规范

> 状态：v2（2026-10-30）。v1 草案经可视化预览验证后按 kou 确认的优化版风格定稿成本版：侧栏 256、菜单激活态浅底＋指示条、内容最大宽分工三项原「待拍板」已按预览定案。视觉基准为同目录 `design-preview.html`（v2 预览，含深色/密度/折叠/抽屉/弹窗可交互演示）。本文数值与 theme.css／组件实现冲突时以本文为准修订代码；任何会话新增或修改页面/元素前必须先读本文，并遵守 `.cursor/rules/admin-web-design.mdc` 的硬约束与自检清单。
> 参考系：**shadcn/ui 的 token 体系**（本仓 token 命名正源于此）与 **Ant Design 后台的尺寸共识**（侧栏 200–256、顶栏 64、4px 间距基准）。

## 0. 设计定调

四个关键词：**克制、扁平、数据优先、低对比分隔**。

- 色彩克制：界面以无彩色（slate 灰阶）为骨，主色只用于主操作、激活态与链接；状态色只表达状态，不作装饰。品牌渐变（primary→chart-2）只许出现在 logo 与头像两处，不进内容区。
- 扁平：内容卡片只用 1px 边框、不用阴影；阴影只属于浮层，按 §2 的两级阶梯取用。
- 数据优先：表格与表单是主角，密度三档服务于「一屏看多少数据」，不是装饰性留白。
- 质感来源（v2 定调）：统一的 Lucide 线性图标体系、150–250ms 的微交互、状态的可视化（呼吸点/趋势线/用量条）——丰富来自信息层次，不来自装饰堆叠。

## 2. 颜色 Token 体系

现状 8 个（background/foreground/card/card-muted/border/muted-foreground/primary/primary-foreground）不够用，导致页面借 rose/slate 原生色与硬编码 hex 补位。目标全表（浅色值沿用现有 slate/blue 色板逻辑，深色成对给出；RGB 三元组制式不变）：

**表面与文字（现有，保留）**：`--background`、`--foreground`、`--card`、`--card-muted`、`--border`、`--muted-foreground`。
**补齐（对齐 shadcn 缺口）**：
- `--popover` / `--popover-foreground`：下拉、浮层专用面；
- `--secondary` / `--secondary-foreground`：次级按钮语义底；
- `--accent` / `--accent-foreground`：hover/选中浅底（起步可与 card-muted 同值，但要有名分）；
- `--input`：输入框边框专用（先登记，层级分不开时启用）；
- `--ring`：聚焦环专用色（= primary 28% 透明的成文形式，终结各处手写 `rgb(var(--primary)/x)` 与 `--admin-primary` 笔误）；
- `--sidebar` / `--sidebar-foreground` / `--sidebar-accent`：侧栏专属面（v2 已采用：浅色 248 250 252、深色比内容面深半档 23 32 48）。

**状态色（新增，各含 base / foreground / muted-bg 三值，浅深成对）**：
- `--danger`（red-600 浅 / red-400 深）、`--success`（emerald-600 / 400）、`--warning`（amber-600 / 400）、`--info`（sky-600 / 400）。
- 使用规则：状态标签＝muted-bg（base 的 10–12% 透明）+ base 深一档文字 + 同色状态点；状态按钮（danger）＝base 底 + 白字（浅色）/ 深底亮字（深色）；**禁止再直接写 rose/emerald/amber 的 Tailwind 类**。
- 对比验收线：任何「文字色×其底色」组合 ≥ 4.5（正文）/ ≥ 3.0（大字与图标），新 token 落地时逐项验算并把结果记在 theme.css 注释里。

**深色修正**：`.dark` 补 `--primary` 提亮至 blue-400（96 165 250，对深色卡面实测 5.75）；深色 primary 底上的文字用深色字（primary-foreground 深色值＝15 23 42）；四个主色预设（蓝/紫/绿/橙）各自补深色值（同色相提亮一档）。

**图表色（正式启用）**：`--chart-1..4`（蓝/紫/绿/橙，深色各提亮一档），趋势线、用量条、统计卡装饰按序取用，禁止各页自选图表配色。

**阴影阶梯（v2 新增，两级）**：`--shadow-pop`（下拉/菜单/toast/可点击卡 hover：浅色 0 4px 16px / slate 8% + 0 1px 3px / 6%，深色以更深的黑 35% 等值）；`--shadow-overlay`（抽屉/弹窗：0 16px 48px / 18% + 0 4px 12px / 10%，深色 50%）。内容卡片默认无阴影。

**桥接**：`@theme inline` 补齐全部 token，页面只用 Tailwind 语义类或 `.bg-admin-*` 语义类，**禁止任意值色与 hex**（图表 SVG 的 stroke/fill 引 chart 变量除外）。

## 3. 间距阶梯

4px 基准，只许用阶梯值（Tailwind 默认刻度同源，成文约束用法）：

| 值 | 用途 |
|---|---|
| 4 | 图标与文字间、标签内、菜单 item 间 |
| 8 | 紧凑元素间（按钮组内、行内操作） |
| 12 | 菜单 item 内、卡片内小区块 |
| 16 | 表单字段纵距、卡片间纵距、工具栏内分组 |
| 20 | default 内容 padding、卡片内 padding（中档） |
| 24 | comfortable 卡片 padding、分区之间 |
| 32 | 页面大分区之间 |
| 40/48 | 空状态上下留白、登录等特殊页 |

禁止 `gap-3.5`、`p-[13px]` 之类阶梯外数值出现在页面里（组件内部实现细节除外，但须回到阶梯值）。

## 4. 布局壳规格

- 侧栏：展开 256 / 折叠 64；高度 100dvh 独立滚动；底色用 `--sidebar`，与内容面以 border 分隔；底部可放一张配额/用量卡（见 §5）。
- 顶栏：高 64，sticky，底色 `--header-background`（半透明+blur），border-b；z-20；右侧放密度分段控件（见 §6）。
- 内容：padding 随密度（14/20/28）；最大宽按骨架分工：数据页 1460 居中封顶、设置/表单页 1200、文档型 880，由骨架模板提供容器类，页面不自设。
- 响应式：≥lg 侧栏常驻；<lg 侧栏抽屉化（遮罩 z-40、抽屉 z-50），顶栏菜单按钮触发。
- **z-index 阶梯定案**：内容 0 / 顶栏 20 / 下拉与浮层菜单 30 / 遮罩 40 / 抽屉与弹窗 50 / toast 70。页面禁止自创 z 值。

**页面骨架（四类，新增页面先对号入座）**：
1. **列表页**：页头（标题+主操作）→ SearchToolbar/FilterTabs → DataTable（内含分页/空/错状态）；
2. **设置页**：限宽 1200，分区卡片纵列，卡内表单用 adminFieldClass，底部 FormActions 右对齐；
3. **详情/编辑页**：页头带面包屑（AdminPageHeader 的 breadcrumb），内容分区卡片；
4. **工作台页**：左二级导航（与侧栏同款 item 规范）+ 右内容区，内容区内再按 1–3 类骨架组织。

## 5. 侧边栏规格

- 品牌区：高 64 与顶栏对齐；logo 块 32、圆角 9、品牌渐变；产品名 15/600；kicker（10px 大写宽距）仅用于品牌区与分组眉题。
- 分组标题：12px、600、大写、tracking 0.12em、muted 色；组间距 24（首组 16），组内 item 间距 2–4。
- 菜单 item：高随密度（32/36/40），图标 18（Lucide SVG），图标-文字 12，圆角 8，文字 14/500；hover＝primary 6% 底；**激活态（定案）＝primary 12% 浅底 + 主色文字 + 左 3px 指示条**；可带计数徽标（高 18、pill、primary 14% 底 + 主色字 11/600，右对齐）。折叠态只显图标，激活浅底块保留。
- 底部配额卡（可选组件）：border + card 底 + 圆角 12，内含标题行（12 muted + 百分比）、6px 用量条（主色）、12 muted 说明；折叠态隐藏。
- 工作台二级导航与主侧栏共用同一 item 规格（尺寸、激活态、分组标题全一致），禁止另写一套。

## 6. 顶部 Navbar 规格

- 左：折叠按钮（36 图标钮）+ 面包屑（当前页主色字重 500，其余 muted，层级以 › 分隔）；页面标题不进顶栏（在内容区 AdminPageHeader），顶栏不重复。
- 右：搜索框宽 240（md 以上显示；静止为 card-muted 底，focus＝主色边 + ring + card 底；带 ⌘K kbd 徽标）、**密度分段控件**（紧凑/默认/舒适三段，seg 样式：muted 底容器 + 选中段 card 底+微阴影；它切换的是用户偏好 data-density，不是页面自己设密度）、深色切换、通知、用户菜单（宽 200）。
- 图标按钮统一 36×36、圆角 8、hover＝primary 7% 底；头像 32 圆形（品牌渐变底 + 白字缩写）。

## 7. 控件规格

**尺寸三档**（高）：sm 28（行内操作、分页、标签旁按钮）／md 随密度 32/36/40（默认主力）／lg 44（页面主 CTA、弹窗确认）。圆角：sm 6 / md·lg 8。

**按钮五类 × 状态矩阵**（底／字／边框取 token，禁止原生色）：

| 类 | 静止 | hover | active | disabled |
|---|---|---|---|---|
| primary | primary 底 + on-primary 字 | 底 92% | scale(.98) 按压 | 50–60% 透明、无指针 |
| secondary | card 底 + border + 主字 | card-muted 底 | 同 hover | 同上 |
| ghost | 透明 + 主字 | primary 7% 底 | card-muted 底 | 40% |
| danger | danger 底 + 白字（三档齐全） | 底 92% | scale(.98) | 60% |
| danger-ghost | 透明 + danger 字 + danger 35% 边 | danger 8% 底 | danger 浅底加深 | 40% |

- focus-visible 全类统一：2px `--ring` 外环 + 2px 偏移（终结逐处手写 ring 任意值）。
- loading：按钮内 spinner 16 替换图标、文字保留、禁点；提交中只禁提交钮，不整表单禁用，防闪烁。

**输入类**：输入框/选择器与 md 按钮同高同圆角；边框 `--input`（未启用时 border），focus＝主色边+ring；占位符 muted；禁用＝muted 底 + muted 字。
**开关/复选/单选**（标准件，禁止各页自写）：开关 36×20、圆点 16（带微阴影）、开态主色底、过渡 150ms；复选/单选 16 方/圆、选中主色底白勾；文字与控件间距 8，整行可点。
**密钥/代码字段**：等宽字体 13、脱敏显示（• 占位）、右侧附 secondary 复制钮（CopyableText 同款行为），明文只在用户主动显示/复制时出现。

## 8. 表单规范

- label 上置：12px/500、与字段间距 6；必填以 danger 色 `*` 后缀；帮助文字 12 muted 在字段下 4px；校验错误文字 12 danger 替换帮助位（错误位预留一行高，布局不跳动）。
- 字段纵距 16（comfortable 20）；双列只用于短字段（≥md 才分列，列距 16）。
- **浮层分工（v2 定案）**：字段多、带说明或分步的表单用**抽屉**（右出 560，结构：头 64 标题+关闭钮／内容滚动／底部操作条以 border-t 分隔、右对齐）；简单确认与短表单用**弹窗**（宽阶梯 S 400 / M 560 / L 720，标题 16/600，内容 padding 20，底部操作右对齐）。危险确认弹窗：左 40 圆角 10 的 danger 10% 底图标徽章，确认钮用 danger，文案必须写明操作对象名与不可恢复性。
- 提交反馈：成功 toast + 关浮层 + 列表刷新；失败保留输入、错误落字段或浮层顶部 alert 区（字段级优先）。

## 9. 表格规格（DataTable 定案）

- 容器：圆角 12、border、无 shadow；表头固定高 40（text-xs 大写、muted、card-muted 底）与行密度脱钩为有意决定。
- 行：高随密度 36/44/52；hover＝primary 4% 底；选中行 primary 8% 底 + 左列复选 16；行操作列右对齐、sm 档 ghost/danger-ghost、间距 4，超过 3 个收进「更多」下拉。
- 列：文字左、数字右（tabular-nums）、状态居中用 StatusTag、时间列等宽数字；**主体列推荐「图标块 34（圆角 9、chart 色底白字）+ 主文 14/500 + 副文 12 muted」双行结构**（账号/入口/用户类列表的标准形态）；用量类列用迷你条（宽 86、高 5、chart 色）；长文本截断 + title/展开，ID、URL、key 类字段用 CopyableText。
- 分页：右对齐，页码钮 28 方、圆角 6、hover primary 7% 底、当前页主色底白字；总数文案 12 muted 在左。
- 状态：加载＝骨架行（行高同密度档，3–5 行）；空＝组件内置空状态；错误＝内置错误态（danger 图标 + 重试）。页面禁止自绘表格或自写空状态。

## 10. 卡片与 Item 规格

- 标准卡：圆角 12、border、card 底、无阴影；padding 随密度 16/20/24；卡头＝16/600 标题（可带 18 图标）+ 右侧操作（sm 钮），卡头与内容间距 12；卡片纵距 16。
- 可点击卡（hoverable）：hover 时边框转 primary 35% + `--shadow-pop` + 上移 1px，过渡 180ms；不可点击的卡禁止加此态。
- 统计卡：标签 12 muted（右侧可挂状态标签）、数字 24/600 tabular-nums、环比行 12（涨 success 跌 danger，带 ▲▼）、**趋势型带 30px 高 sparkline（chart 色 2px 线，无轴）**；四列栅格（<1150px 转两列）。
- 列表 item（非表格场景）：行高最小 56，左图标/头像 34–36，主文 14/500 + 副文 12 muted，右状态或操作；分隔用 border，hover accent。
- 标签（StatusTag 定案）：高 22，圆角全 pill，字 12/500，底＝状态 muted-bg、字＝状态深一档、**前带 6px 同色状态点**；同一状态全站同色（状态→色映射表进附录，新增状态先登记）。
- **组链可视化（产品特色组件）**：按模式分行（行首 64 宽大写分组标），节点＝圆角 10 边框卡（名称 13/600 + 模型 12 muted），主用节点主色边 + 5% 底 + 「主用」标签，失效节点虚线边 + 55% 透明；节点间连线带触发条件小字（如「429/5xx 时」）。用于 AI 设置与代理页的链路呈现，禁止用纯文字描述代替。

## 11. 反馈与浮层

- 状态呼吸点：8px 状态色圆点 + 2s 扩散环动画，仅用于「服务运行中」类活状态，静止状态用普通状态点。
- 页内 Alert：圆角 12、状态 muted-bg + 状态色边 35%、图标 18、主文 14 + 副文 muted、右侧可带 sm 操作钮；与 toast 分工——toast 管操作结果，alert 管页面状态（过期、失败、公告）。
- Toast（sonner）：右下，宽 ≤360，左 3px 状态条 + 图标 + 标题 14/600 + 副文 12 muted；成功 3–3.6s、失败 5s 且可手动关；同类连发合并计数。
- 抽屉/弹窗/遮罩：遮罩 slate-900/45%，抽屉动画 240ms ease-out，弹窗 180ms 缩放+上浮入场；Esc 与点遮罩关闭（危险确认弹窗除外，须显式选择）。
- 时间线（活动/审计呈现）：左 1px border 竖线 + 7px 圆点（重要事件主色边），事件主文 14、时间 11 muted，条目纵距 14。
- 空状态：52px 圆角 14 的 muted 图标盒（图标 24）+ 主文 14/500 + 副文 12 muted + 可选 sm 主按钮；用于空列表、搜索无结果、未配置三类场景，文案须给出下一步动作。
- 骨架屏：圆角 6、muted 10–18% 渐变扫光 1.4s，行高与真实内容同高，禁止用转圈代替内容区加载。

## 12. 图标

- 只用 Lucide（SVG，stroke 2、圆头圆尾、currentColor）；**禁止用字符、emoji 或私有字体充当图标**。
- 尺寸阶梯：14（标签内/行内辅助）、16（按钮内、表单）、18（菜单、卡头）、20（顶栏、工具）、24（空状态、统计）。
- 语义唯一：同一含义全站同一图标（映射进附录：设置＝SlidersHorizontal、代理＝Zap、知识库＝BookOpen 等，新增先登记）；状态图标才用状态色，其余随文字色。

## 13. 字阶与动效

| 号 | 用途 | 字重 | 行高 |
|---|---|---|---|
| 10 | kicker/眉题（大写宽距） | 600 | 1.2 |
| 12 | 辅助、标签、表头、分组标题 | 400/500 | 1.4 |
| 14 | 正文、控件、菜单 | 400/500 | 1.5 |
| 16 | 小节标题、卡头、弹窗标题 | 600 | 1.4 |
| 20 | 页标题（仅 AdminPageHeader） | 600 | 1.3 |
| 24 | 统计数字 | 600 | 1.2 |

字体栈与根字号偏好（14/16/18）保留现状；数字一律 tabular-nums。
**动效定案**：hover/状态色 150ms、卡片 hover 与浮层入场 180–200ms、抽屉与侧栏折叠 200–240ms ease-out、呼吸点 2s 循环；禁止 >300ms 的界面过渡与无意义入场动画。

## 14. 合规自检清单（新增/修改页面或元素后逐项过）

1. 颜色只用 token（无 hex、无 rose/slate 等原生色类、无任意值色）；深色模式下逐屏不露馅。
2. 元素先查组件选用：表格 DataTable、弹窗/抽屉 FormDialog 系、状态 StatusTag、页头 AdminPageHeader、筛选 SearchToolbar/FilterTabs、密钥 CopyableText——有现成不用现成＝不合规。
