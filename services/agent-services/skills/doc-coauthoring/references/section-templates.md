# Section templates (optional detail)

The loader only injects `SKILL.md` today. Keep the active playbook there.
This file is for B-layer progressive disclosure once references are readable.

## Guide / handbook skeleton

1. Purpose and audience
2. Prerequisites
3. Step-by-step procedure
4. Common failures / FAQ
5. Related documents

## Policy / decision note skeleton

1. Context
2. Decision or rule
3. Rationale (with citations)
4. Exceptions
5. Owners / next review

## FAQ skeleton

1. Scope of this FAQ
2. Question → answer pairs (each answer cited)
3. Out of scope / where to ask next
